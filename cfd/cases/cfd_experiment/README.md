# CFD experiment cases (generated, NOT executed)

Reproducible quasi-2D `simpleFoam` RANS k-omega SST cases around a single
building block, generated by `cfd/scripts/generate_cfd_cases.py`.

## Status
**No simulation was run.** OpenFOAM (`blockMesh`, `simpleFoam`) is not
available in this execution environment (macOS Apple Silicon, no OpenFOAM
installation or container image). The cases below are ready to run when a
solver is available.

## Cases
- `case_01_h20_u5`
- `case_02_h20_u7`
- `case_03_h12_u5`
- `case_04_h28_u5`
- `case_05_h20_u3`

## How to run
Source OpenFOAM (or start an OpenFOAM docker container), then in each case:
`./Allrun`. Convert the sampled pedestrian slice with
`cfd/scripts/foam_to_contract.py` and feed the resulting NPZ into the
experiment pipeline (`src.experiment.runner.run_experiment`).

## Limitation
These are 2D vertical-plane cases; the z = 1.75 m slice is a 1D profile over x.
Producing the 2D (x, y) horizontal pedestrian target the surrogate predicts
requires 3D cases (snappyHexMesh over a building array) — the remaining CFD step.
